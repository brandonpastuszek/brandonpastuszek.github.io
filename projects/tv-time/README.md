# TV Time

This folder is an editable TV Time project.

## Update tracked shows

Edit `TV_SHOW_WATCHLIST.md`:

- Use `- [ ] Show Name` to track a show.
- Use `- [x] Show Name` to pause a show without deleting it.
- Keep one show per checklist line.

## Update report behavior

Edit `tv-shows-this-week.md` to change the research rules, report columns, descriptions, previews, or source preferences.
